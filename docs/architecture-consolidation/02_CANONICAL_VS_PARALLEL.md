## Safe interpretation

- The registry and `RouteContent` are complementary responsibilities; treat alignment as a testable contract.
- Translation engine, source catalogs, generated artifacts and runtime dictionaries are separate stages. Do not mistake a machine translation for editorial approval.
- ClickUp’s CRM role is approved. Contact’s Sheets-only current behavior is a code gap. Sheets is not a substitute CRM.
- WordPress cannot become CRM, onboarding/talent database or operational source of truth; Typesense cannot become transactional truth.
- Railway is the preferred target, not a claim that current Compose deployment already runs there. Preserve portability.
- Approved architecture decisions remain frozen unless objective evidence demonstrates technical infeasibility or a new explicit approval supersedes them.
