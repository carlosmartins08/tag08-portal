## Função deste pacote
Este pacote reúne a base verbal global do novo site da TAG08.

Ele deve ser usado antes da criação das páginas específicas para garantir consistência entre:
- posicionamento;
- slogan;
- CTAs;
- navegação;
- SEO;
- footer;
- mensagens institucionais;
- campanha principal.

## Estrutura

```txt
content/
  global/
    slogans.md
    ctas.md
    seo-defaults.md
    navigation.md
    footer.md
    brand-messages.md
```

## Regra de uso
Nenhuma página deve criar promessa, CTA ou frase institucional fora deste padrão sem revisão estratégica.
