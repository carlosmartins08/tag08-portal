# TAG08 Content — Services

Pacote de conteúdo das páginas de serviço da TAG08.

## Objetivo

Documentar o conteúdo das páginas comerciais de serviço com clareza de rota, função, promessa, CTA, SEO, seções, copy e observações de implementação.

## Como usar

Cada arquivo deve ser tratado como fonte de implementação da respectiva rota em `/servicos/...`.

A estrutura de cada página segue o padrão:

1. rota;
2. função da página;
3. promessa principal;
4. CTA principal;
5. SEO;
6. seções da página;
7. conteúdo de cada seção;
8. observações de implementação;
9. FAQs e microcopy quando aplicável.

## Regra editorial

Estas páginas não devem vender entrega isolada. Devem ajudar o visitante a entender o problema, perceber o valor do método TAG08 e dar o próximo passo correto.
