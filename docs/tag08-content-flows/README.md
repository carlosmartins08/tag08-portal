# TAG08 Content Package — Flows

## Objetivo

Este pacote reúne os conteúdos das páginas de fluxo e conversão do site TAG08.

Diferente das páginas institucionais e de serviços, estas páginas têm uma função mais operacional:

- coletar contexto;
- qualificar oportunidade;
- orientar o próximo passo;
- reduzir ruído;
- evitar promessa indevida;
- registrar informações úteis para o time.

## Arquivos incluídos

- `content/flows/cliente-onboarding.md`
- `content/flows/sebraetec.md`
- `content/flows/programa-afiliados.md`

## Regra de uso

Cada arquivo está estruturado por:

1. rota;
2. função da página;
3. CTA principal;
4. SEO;
5. seções da página;
6. conteúdo exato sugerido;
7. microcopy;
8. observações de implementação.

## Atenção

As páginas de Sebraetec e Programa de Afiliados envolvem regras que podem mudar por edital, política comercial ou decisão interna.  
Antes de publicar percentuais, benefícios financeiros ou critérios legais, validar a versão vigente com a liderança da TAG08.
