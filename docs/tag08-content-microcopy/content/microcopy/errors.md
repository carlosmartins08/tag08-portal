- [x] Rascunho estratégico

## Função deste arquivo
Padronizar mensagens de erro do site TAG08 com linguagem clara, útil e sem culpa ao usuário.

## Regra principal
Erro bom diz o que falhou e como corrigir.

---

# 1. Erros gerais de formulário

- Campo obrigatório: **Este campo é necessário para continuarmos.**
- Campo obrigatório com contexto: **Preencha este campo para que a TAG08 consiga entender melhor sua solicitação.**
- Campo incompleto: **A informação parece incompleta. Revise antes de continuar.**
- Formato inválido: **O formato informado não parece válido. Verifique e tente novamente.**
- Limite de caracteres: **O texto ultrapassou o limite permitido. Reduza um pouco para continuar.**
- Mínimo de caracteres: **Inclua um pouco mais de contexto para que a resposta seja útil.**
- Seleção obrigatória: **Escolha uma opção para continuar.**
- Checkbox obrigatório: **Confirme esta informação para prosseguir.**

---

# 2. Erros de dados pessoais

- Nome vazio: **Informe seu nome para sabermos como chamar você.**
- Nome muito curto: **Informe seu nome completo ou o nome pelo qual devemos chamar você.**
- E-mail vazio: **Informe um e-mail para contato.**
- E-mail inválido: **O e-mail informado não parece válido. Verifique se está completo.**
- WhatsApp vazio: **Informe um WhatsApp para contato.**
- WhatsApp inválido: **Informe um WhatsApp com DDD.**
- CNPJ vazio: **Informe o CNPJ da empresa para seguirmos com a análise.**
- CNPJ inválido: **O CNPJ informado não parece válido. Verifique os números e tente novamente.**

---

# 3. Erros de links e arquivos

- Link vazio: **Cole um link para que a equipe consiga acessar o material.**
- Link inválido: **O link informado não parece válido. Verifique se começa com http:// ou https://.**
- Link sem permissão: **Não conseguimos acessar este link. Verifique as permissões de compartilhamento.**
- Arquivo muito grande: **O arquivo excede o tamanho permitido. Envie por uma pasta compartilhada.**
- Tipo de arquivo não aceito: **Este formato de arquivo não é aceito aqui. Envie em PDF, JPG, PNG, MP4 ou por link de pasta.**
- Upload falhou: **Não foi possível enviar o arquivo. Tente novamente ou use um link de pasta compartilhada.**
- Muitos arquivos: **Há muitos arquivos para este campo. Organize em uma pasta e envie o link.**

---

# 4. Erros de envio

- Envio falhou: **Não foi possível enviar sua solicitação. Revise os campos e tente novamente.**
- Erro temporário: **Algo falhou no envio. Aguarde alguns instantes e tente novamente.**
- Conexão instável: **A conexão parece instável. Verifique sua internet e tente novamente.**
- Sessão expirada: **Sua sessão expirou. Recarregue a página e tente enviar novamente.**
- Duplicidade: **Parece que esta solicitação já foi enviada. Aguarde o retorno da equipe antes de enviar outra.**

---

# 5. Erros por fluxo

- Contato — contexto insuficiente: **Inclua um pouco mais de contexto sobre sua necessidade para que possamos orientar melhor.**
- Diagnóstico — objetivo genérico: **Explique o que “crescer” significa para sua empresa neste momento.**
- Onboarding — ausência de responsável: **Informe quem será responsável por acompanhar ou aprovar o projeto.**
- Onboarding — acesso inseguro: **Não envie senhas abertas. Use o método seguro indicado pela equipe TAG08.**
- Sebraetec — CNPJ ausente: **Precisamos do CNPJ para iniciar a verificação de elegibilidade.**
- Sebraetec — localidade ausente: **Informe cidade e estado. As regras podem variar conforme a localidade.**
- Afiliados — perfil incompleto: **Conte um pouco mais sobre sua rede de relacionamento para avaliarmos o fit.**
- Trabalhe Conosco — portfólio ausente: **Envie um link que ajude a conhecer seu trabalho ou experiência.**

---

# 6. Erros de sistema

## Erro 404
**Esta página saiu do caminho.**

Texto de apoio: O link pode ter mudado ou o conteúdo pode ter sido removido. Você pode voltar para a Home ou acessar as soluções da TAG08.

CTAs:
- **Voltar para Home**
- **Ver soluções**

## Erro 500
**Algo falhou do nosso lado.**

Texto de apoio: Não foi possível carregar esta página agora. Tente novamente em alguns instantes.

CTAs:
- **Tentar novamente**
- **Falar com a TAG08**

## Manutenção
**Estamos ajustando esta área.**

Texto de apoio: Esta página está temporariamente indisponível para melhoria ou manutenção.

CTA: **Voltar para Home**

---

# 7. Erros que devem ser evitados

Não usar:

- Erro!
- Ops!
- Algo deu errado.
- Campo inválido.
- Tente novamente.
- Preencha corretamente.
- Falha no sistema.

## Motivo
Essas mensagens não explicam o problema nem ajudam o usuário a corrigir.
