## Função deste arquivo
Padronizar avisos de privacidade, consentimento e uso de dados em páginas, formulários e fluxos do site TAG08.

## Atenção
Este arquivo não substitui uma política de privacidade jurídica. Os textos abaixo são microcopies de interface e devem ser validados juridicamente antes da publicação final, se necessário.

## Regra principal
Privacidade precisa ser clara, específica e proporcional ao contexto.

# 1. Aviso curto para formulários gerais

## Uso
Contato, diagnóstico, páginas de serviço.

## Texto
Usaremos seus dados apenas para responder sua solicitação, entender seu contexto e orientar o próximo passo com a TAG08.

## Checkbox
**Autorizo a TAG08 a entrar em contato sobre esta solicitação.**

# 2. Aviso para formulário de diagnóstico

## Texto

## Checkbox

# 3. Aviso para onboarding

## Texto
As informações enviadas neste onboarding serão usadas para organizar contexto, objetivos, responsáveis, materiais, acessos, escopo e próximos passos do projeto contratado.

## Complemento
O envio deste formulário não altera automaticamente prazos, entregas ou condições comerciais. Mudanças relevantes precisam ser validadas pela equipe TAG08.

## Checkbox
**Autorizo a TAG08 a usar essas informações para planejamento, execução e acompanhamento do projeto.**

# 4. Aviso para upload de arquivos

## Texto

## Complemento
Não envie senhas abertas neste formulário.

## Texto
