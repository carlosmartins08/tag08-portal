# TAG08 Content Package — Microcopy

## Objetivo

Este pacote reúne textos curtos de interface para o site TAG08.

Microcopy não é enfeite. É orientação de decisão, redução de ruído e proteção da experiência.

## Arquivos incluídos

- `content/microcopy/buttons.md`
- `content/microcopy/forms.md`
- `content/microcopy/errors.md`
- `content/microcopy/success-messages.md`
- `content/microcopy/popups.md`
- `content/microcopy/empty-states.md`
- `content/microcopy/privacy-notices.md`

## Princípios

- O botão precisa dizer o que acontece depois.
- O campo precisa pedir uma informação de forma curta e explícita.
- O erro precisa dizer o que falhou e como corrigir.
- A mensagem de sucesso precisa confirmar o envio e orientar o próximo passo.
- O pop-up precisa ajudar a decisão, não pressionar.
- A privacidade precisa ser clara e específica.
- Nenhuma microcopy deve usar promessa exagerada.

## Regra final

Se a microcopy não ajuda o visitante a entender, confiar ou decidir, ela deve ser removida ou reescrita.
