# TAG08 Knowledge System

Este repositório reúne a base estratégica, cultural, comercial, operacional e institucional da TAG08.

Ele existe para preservar clareza, reduzir improviso, orientar decisões e servir como biblioteca de conhecimento para pessoas, agentes, skills e processos internos.

## Princípio central

A TAG08 não é uma agência de posts.

A TAG08 é uma empresa de estratégia, posicionamento, operação e crescimento digital sustentável.

## Função deste repositório

Este sistema deve ser usado como fonte de verdade para:

- estratégia;
- vendas;
- atendimento;
- conteúdo;
- operação;
- desenvolvimento;
- onboarding;
- agentes;
- documentação interna;
- tomada de decisão.

## Regra de proteção

Arquivos de DNA, posicionamento, linguagem e governança não devem ser alterados de forma livre.

Toda evolução estrutural deve ser registrada primeiro como candidata em `17_CHANGELOG.md`.

## Frase institucional

Cultura não é discurso.  
Cultura é comportamento repetido.
